## 服务器端

### 需求
1. 稳定运行
2. 对硬件需求低
3. 不需图形化界面

### 技术栈
1. 整体框架：Node.js + Express（主流且长期支持/云服务器友好/CLI易操作）
2. 功能化组件：用户认证、邮件服务、API代理
3. 数据库：SQLite（用户数据、歌单、收藏）
4. 完整日志系统
5. 清晰标准的接口代码定义以及文档

## 前端

### 需求
1. 简洁风格用户界面
2. 直观明了的跳转方式
3. 便利的用户体验，即用尽量少的操作即可完成目的
