## 修复前端错误处理显示详细验证信息

### 修改文件

1. **`frontend_flutter/lib/core/network/dio_provider.dart`**

   * 修改 `_handleDioError` 方法

   * 同时检查 `message` 和 `error` 字段

   * 解析验证错误数组，提取具体字段错误

### 修复逻辑

```dart
// 修改前
final message = e.response!.data?['message'] ?? e.message;

// 修改后
final message = e.response!.data?['message'] 
    ?? e.response!.data?['error']  // 支持后端 error 字段
    ?? e.message;

// 解析验证错误
if (message.contains('参数验证失败')) {
  // 提取具体的验证错误信息，如 "密码必须包含字母和数字"
}
```

### 预期效果

* 用户名已存在 → 显示 "用户名已存在"

* 密码格式错误 → 显示 "密码必须包含字母和数字"

* 其他验证错误 → 显示具体错误信息
