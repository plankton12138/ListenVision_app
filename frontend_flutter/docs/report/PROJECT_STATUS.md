## 🔑 关键决策点

### ✅ 已确认的决策

1. **认证方案**: 纯 Bilibili 绑定
   - 放弃本地用户名/密码系统
   - 使用 Bilibili QR 码扫描登录
   - 支持多设备绑定

2. **数据库策略**: 新旧分离
   - 保留现有表（users, favorites）
   - 新建独立表（bilibili_*）
   - 使用事务确保一致性
   - 可逆迁移

3. **实施方法**: 阶段化推进
   - 6 个清晰的实施阶段
   - 每阶段包含完整测试
   - 逐步降低风险
   - 预计 2-3 周完成

4. **技术选型**: 系统级加密
   - Android: Keystore
   - iOS: Keychain
   - Windows: Credential Manager
   - Linux: libsecret
