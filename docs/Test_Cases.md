# 测试用例

## 一、音频播放核心功能测试

1. 音频快速切换测试：以每秒至少2次的频率，交替使用播放器界面的"上一首"和"下一首"按钮进行连续15-20次歌曲切换操作，验证播放器能否正确响应每次切换请求，无卡顿、崩溃或播放异常现象。

2. 音频切换后上传功能测试：在完成测试用例1的快速歌曲切换操作后，立即点击界面上的"上传音频"按钮，验证上传功能能否正常启动，上传窗口能否正确打开，且不会因之前的快速切换操作导致功能异常或界面无响应。

3. 多方式音频切换测试：交替执行两种音频切换操作各10次：①使用上一首和下一首功能进行音频切换；②通过点击播放列表中的不同音频条目进行切换。验证两种切换方式能否正确工作，播放器状态能否准确更新，且两种方式交替使用时不会产生冲突或异常。

4. 音频类型切换及状态显示测试：快速交替切换在线音频和本地音频（每种类型至少切换5次），验证以下内容：
   - 播放器状态显示的准确性，包括但不限于播放/暂停状态、进度条、时长显示等
   - 后端处理过程的用户感知性：当进行格式转换、文件下载或文件传输时，界面应提供明确的进度指示或状态提示
   - 切换过程中的过渡流畅性，无明显延迟或界面闪烁
   - 所有状态变化应实时反映在UI上，确保用户对当前系统状态有清晰认知

5. 播放控制功能测试：验证播放器的各项基本控制功能：
   - 播放/暂停按钮状态切换及功能正确性
   - 进度条拖动跳转功能，验证跳转后播放位置准确性
   - 音量调节滑块功能，验证静音/恢复静音切换
   - 循环播放模式切换（单曲循环/列表循环/随机播放）
   - 播放速度调节（如支持0.5x-2.0x）

6. B站视频适配测试：验证B站视频的特殊功能支持：
   - 章节跳转功能：验证视频章节列表显示及点击跳转
   - 选集切换功能：验证多集视频的选集列表及切换
   - 分P跳转功能：验证分P视频的列表显示及跳转
   - 点击跳转原内容：验证能正确打开B站原视频页面

## 二、用户认证与账户管理测试

7. 用户注册流程测试：验证完整的用户注册功能：
   - 输入有效邮箱、用户名、密码进行注册
   - 邮箱验证码接收及验证流程
   - 注册成功后自动登录状态
   - 重复注册同一邮箱的异常处理
   - 无效邮箱格式的错误提示
   - 弱密码的安全性提示

8. 用户登录功能测试：验证多种登录场景：
   - 正确的用户名/密码组合登录成功
   - 错误的用户名或密码的错误提示
   - 连续多次登录失败的账号锁定机制
   - 记住密码功能的持久性
   - 登录状态在应用重启后的保持

9. 忘记密码功能测试：验证密码找回流程：
   - 输入注册邮箱后验证码发送成功
   - 验证码有效期验证（过期后无法使用）
   - 使用正确验证码重置密码成功
   - 新密码生效验证（使用新密码登录）
   - 重置链接/验证码的一次性使用验证

10. 游客模式功能测试：验证未登录用户的权限控制：
    - 游客可正常搜索音频内容
    - 游客可下载音频
    - 游客可播放本地音频
    - 游客可管理本地播放列表
    - 游客无法创建歌单（应有登录提示）
    - 游客无法收藏音频（应有登录提示）
    - 游客无法查看播放历史（应有登录提示）
    - 游客无法访问探索页面（应有绑定提示）

## 三、播放列表管理测试

11. 播放列表基础操作测试：验证播放列表的CRUD功能：
    - 创建新歌单（输入名称、描述）
    - 编辑歌单信息（修改名称、描述、封面）
    - 删除歌单及确认机制
    - 歌单列表排序功能（按创建时间、名称等）
    - 歌单内音频的排序调整（拖拽排序）

12. 歌单内容管理测试：验证歌单内音频的管理：
    - 添加音频到歌单（单首/批量）
    - 从歌单移除音频
    - 将音频从一个歌单移动到另一个歌单
    - 歌单内音频去重功能
    - 歌单内搜索和筛选功能

13. 播放列表播放模式测试：验证不同播放模式：
    - 顺序播放模式下的自动切歌
    - 单曲循环模式的正确循环
    - 列表循环模式在最后一首后的行为
    - 随机播放模式的随机性验证
    - 播放模式切换时的状态保持

## 四、搜索与内容获取测试

14. 音频搜索功能测试：验证搜索功能的完整流程：
    - 输入关键词后的搜索结果返回
    - 搜索结果的分页加载
    - 搜索历史记录功能
    - 热门搜索推荐
    - 搜索无结果时的友好提示
    - 搜索结果按类型筛选（歌曲/专辑/播客/曲艺）
    - 搜索过程中的加载状态显示

15. 音频元数据获取测试：验证内容信息的准确性：
    - 标题信息的正确显示
    - 作者/UP主信息的获取
    - 简介内容的完整展示
    - 封面图片的加载和显示
    - 音频时长的准确获取
    - 发布日期的正确显示

16. 搜索结果排序与筛选测试：
    - 按相关性排序
    - 按播放量排序
    - 按发布时间排序
    - 按时长筛选（短音频/长音频）
    - 按类型筛选（音乐/播客/曲艺）
